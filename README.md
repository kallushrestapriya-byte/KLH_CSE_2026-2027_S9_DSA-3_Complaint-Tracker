# Complaint Tracker

 About the Project

**Complaint Tracker** is a text-based system developed to efficiently manage and search customer complaint records. Each complaint contains details such as complaint ID, category, description, status, priority, and resolution.

The project demonstrates efficient **string pattern searching** using different Data Structures and Algorithms.

 Algorithms Used

* **Knuth-Morris-Pratt (KMP)** – Efficient pattern matching using prefix information.
* **Z-Algorithm** – Uses a Z-array to find pattern occurrences efficiently.
* **Rabin-Karp** – Uses rolling hash for fast pattern searching.

 Features

* Stores and manages complaint records.
* Searches complaints based on specific patterns.
* Displays matching complaint records and IDs.
* Combines multiple complaint files into a single corpus.
* Demonstrates efficient searching compared with brute-force methods.

 Concepts Used

* String Matching
* Pattern Searching
* Hashing
* Data Structures and Algorithms
* Text Processing
